# ADR-008: SM-2 over FSRS for Spaced Repetition

**Status**: Accepted
**Date**: 2026-05-16
**Decided by**: Sam_Architect + Petra_Psychology advisory + Claude gate review

## Context

Aria's flashcard system (Module 3) needs a spaced repetition algorithm. The two leading candidates are SM-2 (SuperMemo 2, 1987) and FSRS (Free Spaced Repetition Scheduler, 2022). Both schedule card reviews to maximise long-term retention.

## Decision

**SM-2** for the MVP (Phase 5 launch). FSRS is a Phase 2 roadmap item.

**Why SM-2 now**:
- Proven: used by Anki (100M+ users) for 30+ years
- Simple pure-Python implementation: ~50 lines, zero dependencies
- Well-documented parameters (ease factor, interval multiplier) — easy to explain to users
- Deterministic: same rating → same next interval. Easier to test and reason about.
- Petra_Psychology advisory: SM-2 is validated by decades of cognitive science research. The marginal retention improvement of FSRS does not justify the implementation risk for MVP.

**Why not FSRS now**:
- FSRS requires 15 training parameters per user, calibrated from review history — complex cold-start problem for new users
- FSRS source code is ~400 lines; significantly more complex to test and maintain
- The stability/difficulty model in FSRS is powerful but opaque — harder to explain to learners ("why do I see this card again in 3 days?")

**Migration path**: FSRS is supported by the `FlashcardReview` schema design (ease_factor, interval, repetitions, next_review columns map directly to FSRS stability/difficulty with a migration). Switching is a business logic change in `flashcards/service.py` only.

## Consequences

**Positive**:
- Felix_Flashcards (Phase 5) ships a working, tested SM-2 implementation quickly
- SM-2 is fully unit-testable with simple input → output assertions
- Users see familiar Anki-style rating system (Again / Hard / Good / Easy)

**Negative/Risk**:
- SM-2 is theoretically less optimal than FSRS for long-term retention in studies
- Ease factor bias: SM-2 can over-penalise difficult items

**Mitigated by**: Phase 2 roadmap includes FSRS upgrade. The database schema is forward-compatible.

## Alternatives Rejected

| Alternative | Why rejected |
|---|---|
| FSRS | Too complex for MVP; cold-start problem for new users; deferred to Phase 2 |
| Leitner box system | Cruder than SM-2; no ease factor adaptation |
| Fixed-interval scheduling | Not spaced repetition at all; poor retention outcomes |
