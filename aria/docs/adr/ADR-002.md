# ADR-002: LLM Provider Hierarchy

**Status**: Accepted
**Date**: 2026-05-16
**Decided by**: Sam_Architect + Claude gate review

## Context

Aria uses LLMs for: (a) real-time conversation responses, (b) post-session analysis (6 passes), (c) comprehension quiz generation, (d) grammar deficit identification, (e) flashcard content generation. Each use case has different latency and quality requirements. Cost must be justified at scale (~34 Pro sessions/month to break even at €9.99).

## Decision

| Role | Dev | Production | Reason |
|---|---|---|---|
| Live conversation | Ollama llama3.1:8b | Claude Haiku 4.5 | Speed; Haiku at $0.25/M tokens is cost-effective |
| Post-session analysis | Ollama llama3.1:8b | Claude Haiku 4.5 | Same — analysis doesn't need Sonnet quality |
| Gate reviews (advisory) | — | Claude Sonnet 4.6 | Deeper reasoning for UX/security/psychology judgment |
| Gate approvals (final) | — | Claude Opus 4.7 | Highest reasoning; invoked exactly 9 times |

**Prompt caching**: All analysis system prompts (>1024 tokens) use `cache_control: ephemeral`. This reduces cost and latency on repeated analysis calls where the system prompt is identical across requests.

**Model routing in production**: The factory always returns a `ClaudeLLMService` with the Haiku model. If a caller needs Sonnet for a quality-sensitive path, it instantiates `ClaudeLLMService(model=settings.CLAUDE_SONNET_MODEL)` directly — this is the only valid exception to the factory pattern.

## Consequences

**Positive**:
- Haiku handles 95%+ of LLM calls; cost per session ~$0.0005 for LLM
- Prompt caching cuts repeated system-prompt costs by ~90%
- Adapter pattern means adding a new LLM (e.g., Gemini) = one new provider class

**Negative/Risk**:
- Haiku quality is good but not Sonnet — grammar spotlights may occasionally miss subtle errors
- Ollama on local GPU means dev LLM quality ≠ prod quality (different model family)

**Mitigated by**: Quinn_QA (Phase 2) validates analysis output quality against a schema — if the quiz has fewer than 10 questions or grammar_spotlight is empty, the gate fails regardless of the model used.

## Alternatives Rejected

| Alternative | Why rejected |
|---|---|
| OpenAI GPT-4o | Comparable cost to Claude Sonnet but no native prompt caching for our use case; vendor lock concerns |
| Gemini Flash | Strong candidate — deferred to Phase 2 roadmap via adapter pattern |
| Ollama in production | GPU-dependent; violates no-GPU-in-prod constraint |
| Single model for everything | Opus for every call would cost ~60× more than Haiku; economically unviable |
