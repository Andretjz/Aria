# ADR-009: Language Input Architecture

**Status**: Accepted
**Date**: 2026-05-16
**Decided by**: Sam_Architect + Claude gate review

## Context

Aria serves a global audience. Users may speak any language (not just the 5 target languages), learn any of 5 target languages (de/en/es/fr/it), and want feedback in their own language. These three settings are independent. The system must handle any combination without language gates at signup.

## Decision

Three independent per-user language settings:

| Setting | Controls | Default | Storage |
|---|---|---|---|
| `input_lang` | Language the user speaks to Aria | "auto" (Deepgram/Whisper detection) | UserPreferences.input_lang |
| `target_lang` | Language being practised | Set at onboarding | UserPreferences.target_lang |
| `feedback_lang` | Language Aria uses for corrections + feedback | "auto" (mirrors input_lang) | UserPreferences.feedback_lang |

**Input language**: Any language Deepgram or Whisper recognises (40+ prod, 99 via Whisper). `detect_language=true` on Gladia/Deepgram streams — handles mid-session code-switching automatically.

**Target language**: de / en / es / fr / it (curriculum built, CEFR vocabulary lists, grammar rules). "More coming soon" shown for others — curriculum expansion is Phase 2.

**Feedback language**: Any language. Claude API natively handles all major world languages. Every system prompt includes: `"Deliver ALL feedback in {feedback_lang_name} (BCP-47: {feedback_lang}). Do not switch languages mid-response."`

**Anonymous users**: Settings stored in `localStorage` as `aria_prefs: {input_lang, target_lang, feedback_lang}`. Authenticated users: synced to `UserPreferences` table.

## Consequences

**Positive**:
- Zero language gates at signup — any user can start immediately
- Settings apply instantly with no save button, no reload (Fiona_Frontend standard)
- Five example configurations (Japanese→German, Chinese→French, etc.) must all work at launch

**Negative/Risk**:
- Claude API quality for rare language pairs (e.g., Hindi→Italian feedback) untested at scale
- Helsinki-NLP translation (Module 4) has limited coverage for some language pairs

**Mitigated by**: If Helsinki-NLP lacks a model for a language pair, the error surfaces in the translation service and the user is shown a "translation not available for this pair" message rather than a crash.

## Alternatives Rejected

| Alternative | Why rejected |
|---|---|
| Fixed input language (choose at signup) | Alienates non-English, non-German speakers immediately |
| Target language = feedback language always | Japanese user learning German doesn't want German feedback they can't read |
| Support only 5 input languages | Arbitrary restriction; Deepgram handles 40+ already |
