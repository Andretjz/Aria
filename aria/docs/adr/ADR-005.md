# ADR-005: FastAPI over Django/Flask

**Status**: Accepted
**Date**: 2026-05-16
**Decided by**: Sam_Architect + Claude gate review

## Context

Aria needs: async WebSocket support (live conversation), async HTTP endpoints, OpenAPI schema auto-generation, Python type annotations throughout, and performance headroom for concurrent sessions. The backend is the continuation of Transcribit's FastAPI foundation.

## Decision

**FastAPI** with **Uvicorn** (development) and **Gunicorn + Uvicorn workers** (production).

Key reasons:
- **Native async**: WebSocket conversation loop requires async I/O. FastAPI is built on Starlette which is ASGI-native.
- **Type-driven**: FastAPI uses Pydantic models for request/response validation — same models used for SQLAlchemy schemas. Type annotations provide free OpenAPI documentation.
- **Performance**: Benchmarks consistently place FastAPI in the top tier of Python web frameworks. Sufficient for 10 concurrent sessions on 2-CPU Fly.io container.
- **Continuity**: Transcribit is already FastAPI. Zero learning curve.
- **Dependency injection**: `Depends()` integrates cleanly with the service factory pattern (ADR-003).

## Consequences

**Positive**:
- Auto-generated OpenAPI docs at `/api/docs` — no separate documentation effort
- Pydantic validation is the only input sanitisation layer needed at boundaries
- FastAPI-Users library provides battle-tested JWT + OAuth2 auth (Phase 2)

**Negative/Risk**:
- FastAPI ecosystem is younger than Django; fewer "batteries included" features
- Gunicorn + Uvicorn worker management requires more configuration than Django's built-in server

**Mitigated by**: FastAPI-Users handles auth. SQLAlchemy handles ORM + migrations. Alembic handles schema versioning. The "missing batteries" are individually solved by best-in-class libraries.

## Alternatives Rejected

| Alternative | Why rejected |
|---|---|
| Django + DRF | Synchronous by default; WebSocket support via Channels adds complexity; not ASGI-native |
| Flask + Flask-SocketIO | No native async; Pydantic integration requires extra wiring |
| Litestar | Excellent framework but smaller ecosystem and community than FastAPI |
